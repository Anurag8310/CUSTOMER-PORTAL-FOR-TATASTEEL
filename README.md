# Tata Steel Customer Portal

## Internship Project

A modern, responsive **Commercial Customer Self-Service Portal** developed as part of an internship project. The application is designed to provide business customers with a centralized interface for managing steel-related services, including order and RFQ management, dispatch tracking, steel price calculation, product specifications, MTC certificates, GreenSteel information, and customer account services.

### Key Modules

* Customer Authentication & Login
* Customer Dashboard
* Orders & RFQs
* Live Dispatch Tracking
* Steel Price Calculator
* Product Specifications
* MTC Certificate Management
* GreenSteel / Zeromet
* Sales Contact Information
* Account Security Logs

### Technology Stack

* HTML5
* CSS3
* JavaScript
* Modular JavaScript Architecture
